## Что здесь

Проект анализирует обращения в поддержку подписки ПРАЙМ по теме «оплата» из учебной базы курса: выборка из 1000 клиентов за полгода, с октября 2025 по март 2026. Ключевая метрика - время решения обращения в часах. В ноутбуке notebooks/hw1.ipynb считается, сколько обращений осталось нерешенными, в какие дни были пики, и проверяются гипотезы о том, почему часть обращений решается долго или зависает

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:irishwis/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```

| Путь | Что это |
|---|---|
| `src/prime/` | код проекта: подключение, метрики |
| `notebooks/` | ноутбуки: разведка, расчёты, графики |
| `pyproject.toml` | какие библиотеки нужны проекту |
| `uv.lock` | какие версии встали на самом деле |
| `.env.example` | образец файла с доступами; настоящий `.env` в репозиторий не идёт |
